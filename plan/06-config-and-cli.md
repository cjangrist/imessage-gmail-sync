# 06 — Configuration, CLI, and Setup Wizard

## Three User-Facing Interfaces

1. **Config file** (`~/.config/imessage-gmail-sync/config.toml`) — persistent settings
2. **CLI arguments** (`imessage-gmail-sync sync --limit 50`) — per-run overrides
3. **Setup wizard** (`imessage-gmail-sync setup`) — interactive first-run guide

---

## Part A: Config File (`config.py`)

### Config File Location

```
~/.config/imessage-gmail-sync/config.toml
```

Directory permissions: `0700`
File permissions: `0600` (contains app password)

### Example Config (`config.example.toml`)

```toml
# imessage-gmail-sync configuration
# Generated by: imessage-gmail-sync setup

[gmail]
# Your Gmail address (also used as the From/To address for all synced emails)
email = "yourname@gmail.com"

# Gmail App Password (16 characters, no spaces)
# Generate at: https://myaccount.google.com/apppasswords
# Requires: 2FA enabled on your Google account
app_password = "abcd efgh ijkl mnop"

# Gmail label where synced messages appear
# This label is created automatically if it doesn't exist
label = "iMessage"

[sync]
# Maximum messages to sync per chat on first sync (0 = unlimited)
max_messages_per_chat = 500

# Default lookback period for first sync (ISO 8601 duration or date)
# Examples: "P30D" (30 days), "P7D" (7 days), "2026-01-01"
default_lookback = "P30D"

# Sync SMS messages in addition to iMessage (true/false)
include_sms = true

# Phone number region for E.164 normalization
phone_region = "US"

# Use IMAP search as secondary dedup check (slower but safer)
imap_dedup_enabled = false

[display]
# Mark synced messages as read in Gmail (true/false)
mark_as_read = true

# Archive synced messages (remove from inbox) (true/false)
archive = true

[advanced]
# Path to imsg binary (default: auto-detect from PATH)
# imsg_path = "/opt/homebrew/bin/imsg"

# IMAP connection timeout in seconds
imap_timeout = 30

# Delay between IMAP APPEND operations (seconds)
append_delay = 0.1

# Verbose logging
verbose = false

# Chat IDs to exclude from sync (comma-separated)
# exclude_chat_ids = [101, 202, 303]
```

### Security: `to` Address Enforcement

The `to` address for all injected emails is **always** `config.gmail.email` — the authenticated IMAP user. This is not configurable. There is no `to_address` field in the config.

Why: IMAP APPEND places messages in *your own mailbox*. Setting `To: someone_else@gmail.com` in the headers would be cosmetically misleading and could confuse users into thinking messages are being sent.

## Part B: CLI Argument Parsing (`main.py`)

### Command Structure

```
imessage-gmail-sync <command> [options]

Commands:
  setup     Interactive setup wizard (first-run)
  sync      Sync iMessage conversations to Gmail
  status    Show sync status and statistics
  chats     List available iMessage chats
```

### `sync` Command Arguments

```
imessage-gmail-sync sync [options]

Options:
  --dry-run              Do everything except inject emails (preview mode)
  --full                 Full re-sync (ignore local state, re-check all)
  --limit N              Max messages per chat (overrides config)
  --since DATE           Only sync messages after this date (ISO 8601 or YYYY-MM-DD)
  --chat-id ID           Sync only this specific chat
  --config PATH          Use alternate config file
  --verbose              Enable debug logging
  --quiet                Suppress progress output (errors only)
```

### `setup` Command Arguments

```
imessage-gmail-sync setup [options]

Options:
  --config PATH          Config file location (default: ~/.config/imessage-gmail-sync/config.toml)
  --non-interactive      Use defaults + env vars instead of prompts
```

### `status` Command Arguments

```
imessage-gmail-sync status

Options:
  --json                 Output as JSON (for scripting)
```

### `chats` Command Arguments

```
imessage-gmail-sync chats [options]

Options:
  --limit N              Number of chats to show (default: 20)
  --json                 Output as JSON
```

### Argparse Implementation

```python
# src/main.py
"""CLI entrypoint for imessage-gmail-sync."""

import argparse
import sys
import logging


def build_argument_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="imessage-gmail-sync",
        description="Sync iMessage conversations to Gmail as threaded email conversations",
    )
    subparsers = parser.add_subparsers(dest="command", required=True)

    # --- setup ---
    setup_parser = subparsers.add_parser("setup", help="Interactive setup wizard")
    setup_parser.add_argument("--config", type=str, default=None)
    setup_parser.add_argument("--non-interactive", action="store_true")

    # --- sync ---
    sync_parser = subparsers.add_parser("sync", help="Sync iMessages to Gmail")
    sync_parser.add_argument("--dry-run", action="store_true")
    sync_parser.add_argument("--full", action="store_true")
    sync_parser.add_argument("--limit", type=int, default=None)
    sync_parser.add_argument("--since", type=str, default=None)
    sync_parser.add_argument("--chat-id", type=int, default=None)
    sync_parser.add_argument("--config", type=str, default=None)
    sync_parser.add_argument("--verbose", action="store_true")
    sync_parser.add_argument("--quiet", action="store_true")

    # --- status ---
    status_parser = subparsers.add_parser("status", help="Show sync status")
    status_parser.add_argument("--json", action="store_true")

    # --- chats ---
    chats_parser = subparsers.add_parser("chats", help="List iMessage chats")
    chats_parser.add_argument("--limit", type=int, default=20)
    chats_parser.add_argument("--json", action="store_true")

    return parser


def main():
    parser = build_argument_parser()
    args = parser.parse_args()

    if args.command == "setup":
        from . import setup_wizard
        setup_wizard.run_setup(config_path=args.config, interactive=not args.non_interactive)
    elif args.command == "sync":
        from . import config as config_module
        from . import sync_engine
        cfg = config_module.load_config(config_path=args.config)
        sync_engine.run_sync(
            config=cfg,
            full_sync=args.full,
            message_limit=args.limit,
            since_date=args.since,
            target_chat_id=args.chat_id,
            dry_run=args.dry_run,
        )
    elif args.command == "status":
        ...
    elif args.command == "chats":
```

## Part C: Setup Wizard (`setup_wizard.py`)

### Purpose

First-run interactive guide that:
1. Checks prerequisites (imsg installed, Full Disk Access)
2. Prompts for Gmail credentials
3. Tests IMAP connection
4. Creates config file
5. Runs dry-run sync
6. Shows the user how to do a real sync

### Non-Interactive Mode

For scripting / automation, the setup wizard can run non-interactively using environment variables:

```bash
GMAIL_EMAIL="user@gmail.com" \
GMAIL_APP_PASSWORD="abcd efgh ijkl mnop" \
imessage-gmail-sync setup --non-interactive
```

### Permission Guidance (macOS)

If Full Disk Access is not granted, the wizard prints:

```
✗ Full Disk Access not granted for your terminal.

To fix this:
  1. Open System Settings → Privacy & Security → Full Disk Access
  2. Click the + button
  3. Add your terminal app (Terminal.app, iTerm2, Warp, etc.)
  4. Restart your terminal
  5. Re-run: imessage-gmail-sync setup
```

### Gmail App Password Guidance

```
To create a Gmail App Password:
  1. Go to https://myaccount.google.com/apppasswords
  2. You may need to enable 2-Step Verification first
  3. Select "Mail" as the app and "Mac" as the device
  4. Click "Generate"
  5. Copy the 16-character password (spaces are optional)

Also ensure IMAP is enabled:
  1. Open Gmail → Settings → See all settings
  2. Go to "Forwarding and POP/IMAP" tab
  3. Under "IMAP access", select "Enable IMAP"
  4. Save Changes
```

## Part D: Logging (`logging_config.py`)

### Colorized Console Output

```python
# src/logging_config.py
"""Colorized logging configuration."""

import logging
import sys

COLORS = {
    "DEBUG": "\033[36m",     # cyan
    "INFO": "\033[32m",      # green
    "WARNING": "\033[33m",   # yellow
    "ERROR": "\033[31m",     # red
    "CRITICAL": "\033[41m",  # red background
    "RESET": "\033[0m",
}


class ColorizedFormatter(logging.Formatter):
    def format(self, record):
        color = COLORS.get(record.levelname, COLORS["RESET"])
        reset = COLORS["RESET"]
        record.levelname = f"{color}{record.levelname:8s}{reset}"
        return super().format(record)


def configure_logging(verbose: bool = False, quiet: bool = False) -> None:
    """
    Set up colorized logging.

    verbose: DEBUG level, show all function entry/exit
    quiet: ERROR level only
    default: INFO level
    """
    level = logging.DEBUG if verbose else (logging.ERROR if quiet else logging.INFO)

    handler = logging.StreamHandler(sys.stderr)
    handler.setFormatter(ColorizedFormatter(
        fmt="%(levelname)s %(message)s",
        datefmt="%H:%M:%S",
    ))

    root_logger = logging.getLogger()
    root_logger.setLevel(level)
    root_logger.addHandler(handler)

    # Suppress noisy third-party loggers
    logging.getLogger("imapclient").setLevel(logging.WARNING)
```
